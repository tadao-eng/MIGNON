# チケット受け渡し表 — Google Apps Script 版

Google ドライブの中だけで動く共有チェック表。チェックの状態はスクリプト本体に保存されるので、
別途スプレッドシートを作る必要はない。全部無料枠で完結し、課金要素はない。

- `Code.gs` — サーバー側(状態の読み書き、同時操作のロック)
- `Index.html` — 画面(チェックボックス、外すときの確認ダイアログ)

---

## 設置の手順(だいたい5分)

### 1. プロジェクトを作る

1. https://script.google.com を開く
2. 左上の **「新しいプロジェクト」**
3. 上の「無題のプロジェクト」をクリックして名前を付ける(例: `チケット受け渡し表`)

### 2. Code.gs を貼る

1. 最初から開いている `コード.gs`(または `Code.gs`)の中身を **全部消す**
2. このフォルダの `Code.gs` の中身を **全部** 貼りつける

### 3. Index.html を追加する

1. 左のファイル一覧の **「+」→「HTML」**
2. 名前を **`Index`** にする(`.html` は付けない。付けると `Index.html.html` になって動かない)
3. 最初から入っている中身を **全部消して**、このフォルダの `Index.html` を **全部** 貼りつける
4. 保存(⌘S / Ctrl+S)

### 4. 公開する

1. 右上 **「デプロイ」→「新しいデプロイ」**
2. 左の歯車 ⚙ → **「ウェブアプリ」** を選ぶ
3. 設定:
   - **説明**: なんでもいい(例: `初版`)
   - **次のユーザーとして実行**: **自分**
   - **アクセスできるユーザー**: **全員**
4. **「デプロイ」**
5. 権限を求められるので承認する。途中で
   **「このアプリは Google で確認されていません」** と警告が出るが、自分が書いたスクリプトなので
   **「詳細」→「(プロジェクト名)に移動」** で進んでよい
6. 出てきた **ウェブアプリの URL**(`https://script.google.com/macros/s/.../exec`)が完成品。
   これを譲る相手に送る

---

## 使い方

- **まだの枠をクリック** → 「誰の分?」を書く欄が出る。名前を入れて「チェックする」
  (Enter キーでも決まる)。名前は空のままでもいい
- **チェック済みの枠をクリック** → 同じ欄に今の名前が入って出る。直して「名前を保存」。
  その下に「チェックを外す」があり、外すとどうなるかの注意が並んでいる
- 名前は行の中に出る。付けた時刻も右に出る(名前だけ直しても時刻は変わらない)
- 開いているタブは15秒ごとに最新を取りにいく。ほかの人のチェックもそのまま出る

## 気をつけること

- **URL を知っている人は誰でもチェックを変えられる**(Google アカウントも不要)。
  相手を絞りたいなら、手順4-3の「アクセスできるユーザー」を
  **「Google アカウントを持つ全員」** にする。ただし相手は Google ログインが必要になる
- **名前も URL を知っている人みんなに見える**。相手の本名を書くのが気になるなら、
  ニックネームやイニシャルにしておく。名前は 30 文字まで(超えた分は切り捨て)、
  空のままチェックすることもできる

## あとから直したいとき

コードを直したあと、**「デプロイ」→「デプロイを管理」→ 鉛筆マーク →
「バージョン」を「新バージョン」→「デプロイ」**。URL は変わらない。

`Code.gs` の中の `DATES`(日付)と `PER_DATE`(1日あたりの枚数)、`NAME_MAX`(名前の長さ)を変えれば、
別の公演にも使い回せる。`Index.html` の中にも同じ `DATES` と `PER_DATE` があるので、
両方を同じ内容に揃えること。

## 全部のチェックを消したいとき

スクリプトエディタで関数 `resetAll` を選んで実行する。画面からは呼べないので、
うっかり押して消える心配はない。
